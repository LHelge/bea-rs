List in_progress tasks whose `updated` is older than a threshold (`--hours N`, sensible default). service::list_stale in the library, `bea stale` in the CLI and a `list_stale` MCP tool, so an orchestrator can release claims held by dead workers. No heartbeat or lease machinery.
